# 六级冲刺 · CET-6 Coach

Windows 桌面版六级复习工具：**词汇间隔复习 + 真题阅读复盘 + 积累本 + 写作/翻译训练**。
Python + Tkinter 开发，纯本地运行，不联网、不上传。

## 下载与运行

**直接使用（推荐）**：到 [Releases](../../releases) 下载 `CET6Coach-portable.zip`，解压后双击 `CET6Coach.exe`。
同目录的 `_internal` 文件夹要一起保留，不要只拷 exe。

**从源码运行**（需要 Python 3.10+，自带 tkinter）：

```powershell
python main.py
```

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 今日复习 | 按优先级给出当天任务：错词重练 → 到期旧词 → 今日新词 → 真题阅读 → 积累本 |
| 核心词汇 | 2163 词分三档（高频核心 / 基础回顾 / 六级拓展）；英译汉 → 汉译英 → 语境选择三阶段；错词本、生词本、词汇表检索 |
| 真题阅读 | 18 套真题（2023–2025 年各 6 套）：选词填空、段落匹配、仔细阅读；学习模式逐题看解析，考试模式整组计时；原文定位、干扰项分析、全文参考译文、重点词汇与长难句；错题可标原因并重练 |
| 积累本 | 作文句式、翻译表达、主题词汇、我的笔记；内置 30 条带使用场景和可替换部分的表达；搜索、收藏、编辑、隐藏答案式复习 |
| 写作训练 | 30 套真题作文题（2022–2025）；30 分钟限时、词数统计、草稿保存；6 套配参考范文与可复用表达，可一键收进积累本 |
| 翻译训练 | 73 套真题翻译（2015–2025）；限时、草稿保存、参考译文对照；6 套配参考译文与翻译要点 |
| 复盘统计 | 分题型正确率、错因分布与下一步建议、词汇状态分布、最近交卷记录 |
| 设置与数据 | 每日目标；单词 CSV / 真题 JSON 导入；备份、恢复、重置；旧版记录自动迁移并备份 |

## 学习规则

- **掌握靠检测，不靠自我感觉**：同一词要在不同日期多次答对，并完成语境题，才进入「已掌握」；之后仍会低频复查。
- **答错不归零**：进入「待巩固」，当天重新到期，本轮内还会再出现 1–2 次，错词历史保留。
- **到期复习优先**：新词是上限，不是必须完成的数量。
- **错因可复盘**：阅读错题可标「词汇不懂 / 句子不懂 / 定位错误 / 逻辑误判 / 粗心」，统计页据此给建议。

## 数据与备份

学习记录默认保存在 `%APPDATA%\CET6Coach\progress.json`，不随程序移动。

如果该目录不可写（受控文件夹、权限限制等），会自动改存到程序目录下的 `data\progress.json`，
「设置与数据」页会显示真实路径。旧版记录会自动读取并迁移，迁移前留一份 `progress_v*_backup.json`。

备份与恢复在「设置与数据 → 学习数据」里操作。

## 内容

- 词库 2163 词，含音标、词性、释义、分层与部分例句
- 真题阅读 18 套（2023–2025），全部配逐题解析：原文定位、正确项依据、干扰项分析、参考译文、重点词汇、长难句
- 作文 30 套真题（6 套配范文），翻译 73 套真题（6 套配参考译文）
- 听力不包含在软件内，请用真题音频自行练习

来源、许可与免责声明见 [THIRD_PARTY.md](THIRD_PARTY.md)。真题著作权归考试主办方，本软件仅用于个人学习。

## 开发

```powershell
python -m unittest discover -s tests        # 运行测试
python -m PyInstaller --noconfirm --clean CET6Coach_portable.spec   # 打包成 dist/CET6Coach-portable/
```

内容数据由 `tools/` 下的脚本生成：

- `build_exams.py`：把真题 Markdown 解析成 `content/reading.json`（需要先准备 `content/raw/` 下的真题源文件）
- `scrape_site.py`：抓取 2024–2025 年真题原文与答案
- `verify_answers.py`：用公开答案页逐题核对
- `build_writing_translation.py`：生成作文与翻译题库
- `fix_vocabulary.py`：词库去重
