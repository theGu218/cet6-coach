# 六级冲刺 · CET-6 Coach 2.1

一个不依赖浏览器的 Windows 原生六级复习软件。Python / Tkinter 开发，PyInstaller 打包，
学习记录只保存在本机，不联网、不上传。

## 直接运行

双击 `dist/启动.bat`，或直接双击 `dist/CET6Coach-portable/CET6Coach.exe`
（同目录的 `_internal` 文件夹要一起保留，不要只拷 exe）。

用的是便携版（onedir）：启动时不需要把自身解压到系统临时目录，所以不会再出现
“Could not create temporary directory!”；首次启动约 3–6 秒，属于正常。

运行时不需联网，也不要求电脑安装 Python。如果启动失败，程序会把详细错误写进
`%APPDATA%\CET6Coach\error.log`，把这行日志发给我就能定位。

## 2.0 / 2.1 版本做了什么

按 `design/重构设计方案.md` 重写：把“页面显示 / 复习算法 / 数据保存”拆开，从“题库堆砌”
改成“今日任务 → 学习练习 → 错题重练 → 间隔复习 → 掌握”的闭环。

| 模块 | 现在的能力 |
| --- | --- |
| 今日复习 | 到期旧词 → 错词重练 → 今日新词 → 真题阅读 → 积累本，按优先级给任务入口 |
| 核心词汇 | 2163 词三档分层（高频核心 / 基础回顾 / 六级拓展）；英译汉 → 汉译英 → 语境选择三阶段；错词本、生词本、词汇表检索；1/2/4/7/15/30 天间隔复习 |
| 真题阅读 | 18 套真题（2023、2024、2025 年各 6 套，全部配逐题解析）：选词填空、段落匹配、仔细阅读；学习模式逐题看解析、考试模式整组计时；原文定位、干扰项分析、全文参考译文（默认隐藏）、重点词汇与长难句；错题可标错误原因并重练 |
| 积累本 | 独立一级导航：作文句式、翻译表达、主题词汇、我的笔记；内置 30 条带使用场景与可替换部分的表达；搜索、收藏、编辑、隐藏答案式复习 |
| 写作训练 | 30 套真题作文题（2022–2025）；30 分钟限时、词数统计、草稿保存；6 套配参考范文、写作提纲与可复用表达，可一键收进积累本 |
| 翻译训练 | 73 套真题翻译（2015–2025）；限时、草稿保存、参考译文对照；6 套配参考译文与翻译要点，可收进积累本 |
| 复盘统计 | 分题型正确率、错因分布与下一步建议、词汇状态分布、最近交卷记录 |
| 设置与数据 | 每日目标；单词 CSV / 真题 JSON 导入；备份、恢复、重置；旧版记录自动迁移并备份 |

### 学习规则（和 1.0 最大的区别）

- **掌握不等于“点一下认识”**：要在不同学习日多次答对，并完成语境题，才进入“已掌握”；掌握后仍低频复查。
- **答错不清零**：进入“待巩固”，当天重新到期，本轮内还会再出现 1–2 次；错词历史保留。
- **到期复习优先**：新词是上限，不允许为凑新词数跳过到期复习。
- **错误原因可复盘**：阅读错题可标“词汇不懂 / 句子不懂 / 定位错误 / 逻辑误判 / 粗心”，统计页据此给建议。

## 内容与来源

- **词库**：2163 词，来自公开整理的六级/四级大纲词表，按词频与难度分三档。
- **真题阅读**：2023 年 6 套（原文来自 `wamich/english-exem-md`，GPL-2.0）+ 2024–2025 年 12 套（原文来自
  english-exam.lazynote.cn 的原卷排版页面，抓取脚本见 `tools/scrape_site.py`）。
  2024–2025 的答案先按站点核对，再逐套独立作答复核（12 套 360 题全部一致）；2023 的答案文件有污染，
  逐题按选项文本核对后修正了 43 处。
  答案原先来自 `Drhm1224/cet6-all-in-one`，该答案文件存在复制粘贴污染；现已用外部公开答案页
  逐题按“选项文本”核对，并用独立作答复核，共修正 43 处答案（仔细阅读 23、选词填空 10、
  段落匹配 10；修正记录见 `content/raw/exam_fixes.json`，真题 JSON 里每题保留 `original_answer`）。
- **逐题解析**：由本项目整理（原文定位、正确项依据、干扰项分析、全文参考译文），**不代表官方标准答案**。
- **作文 / 翻译题库**：来自 `xzyj50609/cet6-translation-writing-corpus` 与上述真题原文；范文与参考译文由本项目撰写。
- **听力**：本软件不做听力训练，请用真题音频自行练习。

已知限制：
- 2023-12-1 的答案文件原本缺段落（L 段并不存在，是答案错位），已按站点答案更正为 A–K 段落体系。
- 新增真题若还没生成解析，界面会显示“解析补充中”，判分、错题与重练不受影响。

## 学习记录

记录保存在 `%APPDATA%\CET6Coach\progress.json`，不随 EXE 移动。

- 2.0 使用 schema 3；首次启动旧记录会自动升级，并把旧文件备份为 `progress_v{版本}_backup.json`。
- 备份请用「设置与数据 → 备份学习记录」。

## 从源码运行 / 测试

```powershell
python main.py
python -m unittest discover -s tests -v
```

内容数据由 `tools/` 下的脚本从 `content/raw/` 的真题源文件重建：

```powershell
python tools/build_exams.py              # 真题阅读 → content/reading.json
python tools/build_writing_translation.py # 作文/翻译 → content/writing.json、translation.json
python tools/fix_vocabulary.py           # 词库去重
python tools/verify_answers.py           # 用外部答案页核对（需联网）
```

## 重新打包

```powershell
python -m PyInstaller --noconfirm --clean CET6Coach_portable.spec
```

产物在 `dist/CET6Coach-portable/`。`CET6Coach.spec`（单文件版）保留但不再分发：
单文件版每次启动都要解压到系统临时目录，在受限环境里会报
“Could not create temporary directory!”。

## 仓库结构

```text
main.py                  启动、主窗口与页面路由
views/                   八个页面（只负责界面与事件）
services/                词汇复习、阅读判分、统计、积累本等业务规则
repositories/            学习记录持久化（JSON + schema 迁移 + 数据目录回退）
content/                 词库、真题、解析、作文/翻译题、积累本种子数据
tools/                   内容构建脚本（真题解析、抓取、答案核对）
tests/                   业务测试、内容完整性测试、界面冒烟测试
design/                  重构设计方案
```

以下内容**不在仓库里**（见 `.gitignore`）：`dist/`、`build/`、`content/raw/`（抓取的原始页面，可用 `tools/` 重新获取）、
`design/screens/`（截图含本机路径）。
